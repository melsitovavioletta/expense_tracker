# Бизнес-трекер: мобильное приложение для учёта доходов и расходов

Приложение на Python и Kivy для учёта финансов малого бизнеса

Лекция «Разработка ПО: мобильное приложение»

## Обзор

Приложение позволяет вести журнал операций, видеть баланс, анализировать расходы по категориям, строить график, выгружать данные в CSV и синхронизировать их с облаком. Интерфейс описан на языке разметки KV, логика написана на Python, данные локально хранятся в JSON-файле. 

В проекте два файла:

- `main.py` - версия из лекции: только расходы, аналитика и экспорт в CSV
- `main_hw.py` - итоговая версия с домашним заданием: доходы и баланс, график, облако

## Стек

Python, Kivy (интерфейс, RecycleView, JsonStore, UrlRequest), KV-язык, matplotlib, Kivy Garden, Firebase Realtime Database.

## Запуск

### 1. Подготовка

Нужен Python не менее 3.8. Создать виртуальное окружение и установить зависимости:

```
python -m venv venv
venv\Scripts\activate            # Windows
source venv/bin/activate         # macOS / Linux

python -m pip install kivy matplotlib kivy_garden.matplotlib
```

### 2. Запуск приложения

```
python main_hw.py
```

## Что умеет система

- Добавлять операции двух типов, «Расход» и «Доход», с категорией, описанием и суммой.
- Проверять введенные данные: выбрана ли категория, заполнены ли поля, положительная ли сумма. При ошибке показывается сообщение.
- Показывать список операций (новые сверху): расходы красным, доходы зелёным.
- Считать итоги: общие доходы, общие расходы и баланс.
- Группировать операции по категориям в окне «Аналитика».
- Строить столбчатую диаграмму расходов по категориям.
- Выгружать все операции в `expenses_export.csv`, который открывается в Excel.
- Синхронизировать данные с облачной базой Firebase.
- Сохранять данные между запусками в `expenses.json`.

Категории расходов: офис, зарплаты, маркетинг, логистика, налоги, прочее.
Категории доходов: продажи, услуги, инвестиции, прочее.

## Что сделано в домашнем задании

### 1. Доходы и баланс

- В запись добавлено поле `kind` (`expense` или `income`), в окне добавления появился выбор «Тип операции» со своим списком категорий.
- Вместо «Общего расхода» на экране три показателя: «Доходы», «Расходы» и «Баланс» (красный, если расходы больше доходов).
- Доходы в списке зелёные со знаком «+», расходы красные со знаком «−». Старые записи без `kind` считаются расходами.

### 2. График расходов

- Кнопка «График» строит столбчатую диаграмму расходов по категориям на matplotlib и встраивает её в Kivy через `FigureCanvasKivyAgg` (Kivy Garden).
- Если модуль Garden недоступен, график показывается как PNG-картинка, и приложение не падает.

### 3. Синхронизация с облаком

- Кнопка «Облако» через REST API Firebase скачивает записи из облака (GET), добавляет недостающие локально и отправляет объединённый набор обратно (PUT).
- Запросы асинхронные, ключи записей без точки (требование Firebase), ничего не удаляется. Результат или ошибка выводятся в окне и в консоли.
